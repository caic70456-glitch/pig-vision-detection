## 五、投放策略建议（决定能不能收到 50 份）

### 关键：只靠一个群大概率收不够

微信群里问卷回收率通常只有 **5%–15%**。要拿到 ≥50 份，需要**至少 400–600 人看到**。

| 渠道 | 预期回收 | 备注 |
|---|---|---|
| 本班/本专业群 | 15–25 份 | 同学是"相关专业"身份，属有效样本 |
| 学院大群 / 年级群 | 10–20 份 | |
| 家乡的村镇群 / 老乡群 | 5–15 份 | **最有价值**——里面可能有真养殖户 |
| 父母/亲戚转发到他们的群 | 10–20 份 | 农村地区的家长群往往有养殖从业者 |
| 定向私聊认识的养殖户/基层兽医 | 3–8 份 | 数量少但质量最高，且能拿到访谈素材 |
| 朋友圈 | 5–15 份 | |

### 三个提高回收率的具体做法

1. **先私聊再发群**。群里直接甩链接，大家容易划过；私聊问一句"方便帮我填个问卷吗"，
   成功率能高好几倍。
2. **说明具体时长和题量**（"3 分钟""19 道选择题"）。不写清楚大家怕点开是个长问卷。
3. **在群里发完隔 3-4 小时补一句**："还差几份，再麻烦一下有经验的朋友"——
   二次提醒通常能再多回收 30%。

### 时间安排（今天 10-03，作品 10-07 20:00 截止）

| 时间 | 动作 |
|---|---|
| **今晚** | 问卷星发布 → 拿到链接 → 先发给 3-5 个熟人试填，确认没有歧义 |
| **10-04 上午** | 群发 + 朋友圈 + 定向私聊（第一波） |
| **10-04 晚** | 补发提醒（第二波） |
| **10-05** | 统计结果，把数据回填进作品方案的「需求调研」表格 |
| **10-05 晚** | 定向私聊做 3-5 个深度访谈，补充定性材料 |

## 六、问卷星发布步骤（5 分钟）

1. 打开 **wjx.cn**，微信扫码登录（免注册）
2. 点「创建问卷」→「调查」→「从空白创建」
3. 标题填：**生猪养殖行为监测与疫病早期发现需求调研**
4. 把 `需求调研问卷_可直接发布.md` 里的**卷首语**粘到「问卷说明」
5. 逐题添加：19 道题，题型按文档标注（单选/多选/填空）
   - 第 4、8、9、11、14、16 题为**多选**，其余为**单选**
   - 第 19 题为**填空（选填）**
6. 第 3 题后设置**逻辑跳转**：选 E 则跳到第 15 题
7. 点「发布」→ 选择「微信分享」→ **复制链接**
8. 把链接替换进上面文案的【问卷链接】处

**提示**：问卷星免费版足够用，能看统计图表并导出 Excel，方便直接填进方案。

## ⚠️ 三个必须注意的点

1. **问卷里不要出现学校名称**。大赛要求作品材料中不出现参赛学校名称，
   问卷卷首语已写成"动物科学相关专业的在校学生"，别自己加回去。
2. **不要编造数据**。回收多少就写多少（如"有效问卷 43 份"），
   评审若追问来源，编造会直接失信。
3. **不要把问卷链接发到竞赛官方群**（如校赛群 974961280）。
   那是赛事通知群，发调研链接会被视为刷屏，可能影响印象。
   发自己的同学群、老乡群、家乡群。
